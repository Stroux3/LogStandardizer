# LogStandardizer

Консольная программа для стандартизации лог-файлов, содержащих записи в разных форматах.

## 📌 Возможности

- Поддержка двух форматов входных логов
- Преобразование записей к единому виду
- Запись невалидных логов в отдельный файл
- CLI-интерфейс для работы с файлами

## 💡 Форматы входных данных

### Формат 1:
```
10.03.2025 15:14:49.523 INFORMATION Версия программы: '3.4.0.48729'
Дата: 10.03.2025
Время: 15:14:49.523
УровеньЛогирования: INFORMATION
Сообщение: Версия программы: '3.4.0.48729'
```

### Формат 2:
```
2025-03-10 15:14:51.5882| INFO|11|MobileComputer.GetDeviceId| Код устройства: '@MINDEO-M40-D-410244015546'
```

## 📤 Выходной формат

```
Дата (ДД-ММ-ГГГГ)
Время
Уровень логирования (INFO / WARN / ERROR / DEBUG)
Вызвавший метод (или DEFAULT)
Сообщение
```

Поля разделяются переходом на новую строку. Каждая запись отделяется пустой строкой.

## ⚠️ Обработка ошибок

- Некорректные или нераспознанные записи будут сохранены в `problems.txt` в исходном виде.

## ▶️ Запуск

```
dotnet run --project LogStandardizer.App -- input.txt output.txt problems.txt
```

- `input.txt` — файл с логами
- `output.txt` — файл со стандартизированными записями
- `problems.txt` — файл с ошибками

## 📁 Структура проекта

- `LogStandardizer.Core` — логика парсинга и обработки
- `LogStandardizer.App` — консольный интерфейс
- `LogStandardizer.Tests` — модульные тесты

**input.txt:**
```

```

```
10-03-2025
15:14:51.5882
INFO
MobileComputer.GetDeviceId
Код устройства: 'XYZ'
```
